# Example article title

> This file is a format reference for `12_publish_article.py` and
> `14_publish_batch.py`. Real article files are gitignored (see
> the project `.gitignore`).

---

## Section heading

Body paragraph. **Bold runs get a red inline-style** when rendered for
WeChat MP, so emphasis carries through Tencent's HTML scrubber.

* Bullet points work.
* So do nested headers, `## h2` and `### h3`, with appropriate styling.

---

## Another section

Drop a horizontal rule between sections — the renderer turns those
into dashed dividers that match the WeChat MP house style.
